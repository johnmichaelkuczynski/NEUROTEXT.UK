---
name: Homework input roles
description: User-defined roles for the two Homework boxes.
---
The first Homework box is the assignment itself. Users type, paste or upload the assignment there, including screenshots read through Mathpix. The second box is optional supporting materials, such as one or more articles referenced by the assignment.

**Why:** The user explicitly rejected a first box for additional instructions followed by a second box for the assignment. Supporting articles must not be mistaken for assignment instructions.

**How to apply:** Preserve these roles in upload destinations, labels, persistence and model prompts. Do not replace the first box with an extra instructions field.
