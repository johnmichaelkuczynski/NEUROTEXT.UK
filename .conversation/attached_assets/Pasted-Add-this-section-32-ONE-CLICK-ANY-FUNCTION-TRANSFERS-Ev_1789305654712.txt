32. ONE-CLICK ANY-FUNCTION TRANSFERS

Every function must be able to send its current output directly to any of the other nine functions with one button click.

The transfer controls must be available in the Live Document window and the saved result area.

Display direct destination actions for all ten functions:

Send to Function 01.

Send to Function 02.

Send to Function 03.

Send to Function 04.

Send to Function 05.

Send to Function 06.

Send to Function 07.

Send to Function 08.

Send to Function 09.

Send to Function 10.

Do not require the user to:

Copy the document manually.

Download and re-upload it.

Close the Live Document.

Navigate to another page first.

Select a destination and then press a separate confirmation button.

Repeat the original instructions.

A single click on a destination must immediately copy the complete current output into that function’s source-document field.

The originating function must retain:

Its source document.

Its instructions.

Its target word length.

Its selected model.

Its generated output.

Its saved outline.

Its word count.

Its completion or interruption status.

The destination function must receive the transferred output as its source document.

The destination must visibly display “Paper retained” after receiving the transfer.

The transfer must persist across page reloads.

The transfer must work from every function to every other function, including:

Function 01 to Function 08.

Function 08 to Function 06.

Function 06 to Function 05.

Function 05 to Function 01.

Function 10 to Function 03.

Every other possible source-and-destination combination.

The current function must never be cleared after a transfer.

The transferred document must not be removed from the source function. “Move” in the interface means sending a working copy, not deleting the original.

If the destination already contains work, preserve that work before inserting the transferred document. Do not silently destroy an existing destination document.

After transfer, provide a direct action to open the destination function.

The user must not be forced to navigate immediately. They may continue working in the originating function.

Transfer the exact complete output, including:

Title.

Headings.

Paragraph breaks.

Citations.

Bibliography.

Screenplay formatting.

Dialogue formatting.

Translation structure.

Do not transfer:

Internal prompts.

Hidden outlines.

Diagnostic metadata.

Provider credentials.

Control labels.

Interface text.

Transfer actions must remain available for completed, interrupted, and resumed documents whenever usable output exists.

One-click transfer acceptance test:

Generate output in Function 01.

Click “Send to Function 08.”

Confirm Function 01 still contains the original output.

Confirm Function 08 immediately contains an identical copy in its source field.

Reload the application.

Confirm both functions still retain their respective documents.

Repeat the test from Function 08 to Function 06 and from Function 06 to Function 10.

The transfer feature passes only when any function can send its output to any other function with one click while preserving the source workspace.
