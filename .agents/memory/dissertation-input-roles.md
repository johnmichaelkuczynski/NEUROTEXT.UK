---
name: Dissertation input roles
description: User-defined distinction between a dissertation draft and supporting reference material.
---

For the dissertation writer, the source-document upload is for reference material. An existing dissertation or preliminary dissertation that the user wants polished belongs with the instructions, not in the reference-material box.

**Why:** Dr. Kuczynski explicitly distinguished the work being revised from the sources used to support it.

**How to apply:** Preserve this distinction in future dissertation upload, editing, and prompt changes; do not make users put their draft in the references field.
