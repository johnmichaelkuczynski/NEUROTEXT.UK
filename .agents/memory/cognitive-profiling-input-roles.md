name: Cognitive profiling input roles
description: User-defined document-first layout and default task for Cognitive Profiling.
---
Cognitive Profiling profiles the author of the supplied document. The first box is where the user types, pastes or uploads the text whose author is to be profiled. The second box is for special requirements and is optional.

**Why:** The user explicitly corrected the generic instructions-first layout and required profiling to work without special requirements.

**How to apply:** Keep the document first and the optional requirements second in the interface and model input roles. The default task is an author cognitive profile, not rewriting or summarizing the supplied document.
