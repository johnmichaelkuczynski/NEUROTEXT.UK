---
name: Dissertation input roles
description: User-defined distinction between a dissertation draft and supporting reference material.
---

For the dissertation writer, keep three distinct steps: Step 1, Instructions; Step 2 (optional), Upload Rough Draft; Step 3 (optional), Source Material. A dissertation or preliminary dissertation is the manuscript to transform, never a long set of task instructions.

**Why:** Dr. Kuczynski explicitly requested separate steps so a lengthy protodissertation is not mistaken for instructions on how to write a dissertation.

**How to apply:** Preserve the three roles in future dissertation upload, editing, persistence, and prompt changes. The manuscript's subject and arguments are the content to develop, not directives to follow.
